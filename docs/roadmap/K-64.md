### K-64: A running card on the board has no Stop

Status: Done in #151. Found on 2026-11-07 while planning how a user puts their agent to sleep.

A card that runs shows only a disabled play button on the board. To stop the run, the user has to
find the card's conversation under Coding agents, or the request in the chat, where `cancelRun`
already offers Stop or Cancel (R-030). Users who want their agent to stop look on the card first.

Fix: while a run may still go, the card's play button becomes Stop, which sends the same cancel. A
request still being sent has no message id yet, so it shows no Stop. After a cancel the button
shows Stopping… until the agent reports, so a second click sends nothing.
