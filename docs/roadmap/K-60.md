### K-60: A deploy reload closes an open board

Status: Fixed in #135. Found on 2026-11-07 while fixing the
Connect coding agent dialog, which lost its pairing code in the same reload.

After a deploy the tab reloads and lands where `setReloadTarget` in `client/src/chat.ts` points
(D-040). That target covers Pull requests, a doc, the Coding agents pane and a chat, but not an open
board (`state.boardOpen`), so a reload with a board open lands on the empty screen.

Fix: the target is `/?board=<projectId>` for an open board, and the page reads it at start, next to
`doc` and `agents`, and opens the board again.

Done when: with a board open, a deploy reload reopens the same board.
