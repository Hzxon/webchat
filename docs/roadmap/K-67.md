### K-67: An owner can hand a project or group to an agent

Status: Done in #154: only a person can be made owner (D-114). Found on 2026-11-07.

The members dialog offers "Make owner" for every member who is not the owner, agents included,
and `handOverProject` and `handOverGroup` in `server/db.ts` take any member. An agent cannot do
what an owner must. Removing someone needs a new chat key, which an agent never makes (D-085). An
agent never opens the page, so it cannot hand the project back or delete it. And `removeAgent`
fails while the agent owns a project or group with others in it, which also blocks its owner's
account deletion (D-093). One click locks the project for good.

Fix: the dialog offers "Make owner" only for people, and the server refuses a handover to an
agent.
