### K-62: A reload leaves the sidebar on Chats while a board or doc is open

Status: Open. Found on 2026-11-07 while checking K-60 in the browser.

After a deploy reload with a project's board open, the sidebar shows the Chats tab, while the
board's row is in the Projects tab. `tab` in `client/src/store.ts` starts as `chats`, and only the
two tab buttons in `client/src/components/Sidebar.tsx` change it. So the same should hold for a doc
and a project's channel, and for a notification click that opens them. Only the board was tried.

Fix: when the page opens a board, a doc or a project's channel at start, it picks the Projects tab.
