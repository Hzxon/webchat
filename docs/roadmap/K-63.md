### K-63: A reload closes the editor of a board card or doc section

Status: Open. Found on 2026-11-07 while checking K-60 in the browser.

A deploy reload opens the same board or doc again (K-60), but not the editor of the card or section
that was open: nothing in the reload address names it. Nothing typed is lost, because
`SectionEditor` in `client/src/components/DocView.tsx` keeps a draft on the device at every change,
saves to the server after a second without typing, and brings the draft back on the next edit. The
person has to press Edit again. A reload only comes once the tab is hidden or idle for 30 seconds
(D-040), so it reaches an editor that was left open.

Fix: either hold the reload while an editor is open, as `holdReloadWhile` does for a draft in a
chat, or reopen the editor from the address. The hold keeps a hidden tab on the old build; the
reopen needs the section in the address and a new lock. Choose when taking it.
