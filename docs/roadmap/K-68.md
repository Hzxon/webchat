### K-68: A new card on the board cannot be cancelled

Status: Done in #163: a new section's editor offers Cancel. Found on 2026-11-07 by the owner.

The editor of a new section offers only Done, and its Delete shows only for a section the server
already holds. A new card starts from its template, so `SectionEditor` in
`client/src/components/DocView.tsx` saves it for everyone a second after it opens. Every click on
"+ Idea", "+ Issue" or "+ Decision" leaves a card behind, which the user then has to open and
delete. A new section in a doc has the same gap once the user has typed.

Fix: the editor of a new section offers Cancel. It drops the text and removes whatever of the
section the server already holds.
