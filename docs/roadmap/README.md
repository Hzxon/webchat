# Pending roadmap entries

Each file here is one new entry for [roadmap.md](../roadmap.md), named by its id, such as
`K-59.md`, in the same form as an entry there: the `### K-59: title` heading, the status line and
the body. A pull request adds its entry here instead of inserting into roadmap.md, so two pull
requests never insert at the same spot (D-106). The housekeeping pull request moves these files
into roadmap.md and deletes them.
