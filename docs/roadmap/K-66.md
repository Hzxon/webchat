### K-66: The agent has no off switch, and a hidden window takes over

Status: Done in #153 (D-113). Found on 2026-11-07 while planning how a user puts their agent to sleep.

The only way to stop the agent was to close every Claude Code session on the laptop. Every session
starts the plugin's server, background jobs and editor integrations included, and each one waits for
`watch.lock`. When the window the user works in closes, one of these takes the lock and serves the
agent where the user cannot see it. Neither the page, the README nor `/webchat:connect` says how to
turn the agent off.

Fix: one switch, a file `asleep` in the plugin's data folder. The pane's Put to sleep button sends
the owner's signed `sleep` message, and `/webchat:sleep` writes the file too. The serving window
finishes what runs, starts nothing new, then stops checking in and frees the lock. No window takes
it while the file exists. Only `/webchat:wake` on the laptop removes it. A background job never
serves at all.
