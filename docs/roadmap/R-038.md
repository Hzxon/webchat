### R-038: The Coding agents pane lists projects, and a conversation belongs to one

Status: Planned. Decided with the owner on 2026-11-06. Builds on R-036 for the "no folder" state
and for answers with no folder at all.

Why: the Coding agents pane lists conversations per agent, and its Ask box names a repository
(D-103). Students think in projects, not repositories, and a project with no repository gets no
answer at all (D-102). WebChat is for project collaboration, not for prompting a coding agent the
way Claude Code or ChatGPT is: the agent's value is that it knows the project's board, decisions and
repositories, so the pane should be organized by project.

Scope:

- The pane lists the user's projects. Under each project: its linked repositories (D-050) with
  their state on the laptop (ready, no folder, asleep), and its conversations, newest first. A
  project whose agent is not a member offers to add it, since the agent reads a board only as a
  member (rule 5).
- A conversation is created in a project, with one of its repositories picked at creation when
  there are several, and both signed into the prompt. D-104 already signs the board; the repository
  moves next to it. The conversation keeps D-102 otherwise: its own background Claude session,
  replies resume it, turns of one conversation queue, different conversations run in parallel, and
  it ends after 24 hours.
- A project with no linked repository gets board-only conversations: any online window of the
  agent answers from the board alone, with no folder and no checkout. This is the non-programmer's
  case.
- Nothing an agent produces is posted to a channel. Answers stay in the conversation, card drafts
  reach the board only through the owner's button (D-104), and the pull request card that a linked
  repository already posts (D-050) stays as it is.
- Open choice, to settle when this starts: a conversation's working copy stays a scratch copy in
  the temp folder (D-102), or becomes a worktree under the repository's folder, which sees the
  owner's local branches and costs disk under `~/WebChat`.

Decisions: rewrite D-103, and D-102 if the working copy changes.

Done when: a user with two projects, one with a repository and one without, asks a question in
each from a phone and gets an answer in both, and the pane shows each conversation under its
project. Tested at desktop width and at 375 pixels, in light and dark mode.
