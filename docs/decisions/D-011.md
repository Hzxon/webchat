### D-011: Limits live in one place

Status: Accepted 2026-11-01 in 74d53ff. Changed in #310: the ciphertext limit follows the padding of D-059.

`LIMITS` in `shared/types/limits.ts` holds the sizes that the server enforces and the page respects:
4,000 characters per message, 160 per quote, 43,712 characters of ciphertext (the 32 KB band of
D-059 in base64url), the lengths of names, 50 messages per history page, and 20 people added to a
project or group at once. Express accepts JSON bodies of up to 256 KB (`server/app.ts`). That caps
batch requests: adding 20 people to a project sends every channel's key wrapped for each of them.
Removing someone sends a new key for every channel, wrapped for each person who stays, with the old
key inside (D-044). A copy takes about 110 bytes, so 256 KB holds about 2,300 copies, for example
40 people with 58 channels. A body over the limit, or one that is not JSON, gets a JSON error the
page can show.

Cost: raising a limit can need a larger body limit too. Check both.
