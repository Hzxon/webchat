### D-038: These documents are the source of truth

Status: Accepted 2026-11-01. Changed in #310: once the board is linked, it is the source (D-117).

`AGENTS.md` is the entry point for people and agents, and `CLAUDE.md` imports it so Claude Code
loads it in every session. Decisions, future work, known issues and open questions live on the
project's board. Once the board is linked, `docs/decisions.md` and `docs/roadmap.md` are copies its
owner's agent writes, and a pull request proposes a change as a file (D-117). Each pull request
updates them, or proposes the change, along with the change it makes.

Cost: these documents are only as good as their upkeep. A pull request that changes a decision
without proposing the change misleads the next agent, and main's copy lags the board until the
owner merges the agent's draft.
