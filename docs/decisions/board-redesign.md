### D: The board shows four lanes and a finished lane on demand

Status: Proposed 2026-11-22 in #299.

The Roadmap shows Idea, Ready, Running and In review as tinted lanes of cards; Done shows only when
asked for, newest three first. Each lane sorts by newest, oldest, owner or id, shows all cards,
the user's or those with no owner, and folds into a chip in the header. A new card starts only in
Idea or Ready, since a run moves it on. A card that waits for the user is tinted amber in its lane,
which replaces the row of what waits above the lanes; the Ideas and Issues filter goes too. The
peek's header holds History and Delete only: a run starts from the empty run pane and stops from
the run's own box. It changes D-082 and D-150, where the Roadmap shows Ready, Running and
In review, with Open cards in a drawer and Done folded. Cost: what waits in a folded lane or in Done shows nowhere until it is opened,
and sort and show reset when the page reloads.
