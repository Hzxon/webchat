### D-146: An agent serves from a daemon or from the Claude Code plugin

Status: Superseded by D-141 in #209, where the plugin stopped hosting the agent. Proposed 2026-11-09 in #177 (the daemon-host card).

The plugin's agent had a second host: `npm run agent -- serve` built the same class in
`~/.webchat/laptop`, with `connect`, `sleep` and `wake` as subcommands in place of the `/webchat:`
skills. The plugin stayed the first install, and the daemon served a laptop with no Claude Code
window to keep open. Why: the trusted half of the agent ran only inside a Claude Code session,
whatever harness a laptop had.
