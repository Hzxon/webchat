### D-012: Query strings through the WHATWG URL API

Status: Accepted 2026-11-01 in d4083df. Changed in #310: the helper moved.

Reading `req.query` makes Express call Node's `url.parse()`, and Vercel then logs its deprecation
warning (DEP0169). Routes read query strings with the WHATWG URL API instead: some inline, the
others through the `queryOf` helper in `server/api/helpers.ts`.
