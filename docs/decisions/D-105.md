### D-105: A card runs from a brief its owner saw and signed

Status: Accepted 2026-11-06 in #122 (R-035), changed in #168 (R-042). Changed in #310: every linked harness that takes cards runs them, on the agent's own login.

A card's play button opens its brief in the Coding agents pane: the card and the decisions the team
holds, without the superseded ones, raw, each teammate's passage marked with their name, and a line
that the agent follows it with its own GitHub login (D-092). Start sends the request in the owner's
direct chat with the agent, with the hash of that brief and the card's status; the agent refuses one
without the hash or whose brief changed. The agent names `AGENT_LEVEL.cards` only while its `gh`
login works and a linked harness takes cards (D-119, D-152). A review by anyone but the owner waits
for the owner's go, which names the review's report; only the text that report showed runs. CI,
conflicts and the owner's reviews start a round on their own, and the owner's rounds count toward
no limit. A go also resumes a run that waits for a decision (D-118). Watching outlasts Ready for
review and ends with a report. Why: text teammates wrote runs with the agent's login, so the owner
sees it first.

Cost: a card edited between the brief and the claim must be started again.
